## The problem

Case files are long, sensitive, and slow to read. The data could not leave the department's environment, which ruled out every off-the-shelf AI service.

## What we built

A self-hosted language-model system that summarises case files, tags evidence and routes work through the case-management workflow, inside the client's security perimeter. Nothing leaves the environment, and every summary is produced with an audit trail as a by-product of running the system.

## Outcome

- Case files summarised in production, inside government security controls
- In-jurisdiction, self-hosted deployment with audit evidence built in
