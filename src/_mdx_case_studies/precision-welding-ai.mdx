## The problem

Weld quality depends on direction, angle, and travel speed — variables that traditionally live in a welder's hands and are verified only after the fact, when a defective weld is already made.

## What we built

A helmet-mounted computer vision system that watches the weld as it happens and guides the operator on direction, angle, and velocity in real time. The models run on embedded hardware at the edge — on the shop floor, without a round-trip to the cloud — because guidance that arrives late is guidance that doesn't exist.

## Outcome

- Live in steel plants and welding workshops
- Weld guidance moved from post-hoc inspection to real-time correction
- Proven pattern for embedded, real-time industrial CV

## Stack

Real-time computer vision, embedded edge inference, custom-mounted hardware.
